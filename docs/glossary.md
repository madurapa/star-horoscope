# Glossary — modern display vocabulary

> Status 2026-09-24 (remove_legacy R6b): Old (STAR.EXE-literal) columns
> dropped per owner ruling — modern vocabulary only. The pre-removal
> Old→New table survives in the `legacy` branch (R0 safety).

- **Term**: spelling or text as printed by the app.
- **Note**: intentionally empty (reserved for translator/reviewer notes).

## Summary

- 346 rows total: 87 hand-curated UI terms + 259 generated coded rows
  (13 planets, 12 rasis, 6 vargas, 26 cities, 9 dasa lords,
  27 nakshatras, 7 weekdays, 27 yogas, 30 tithis, 11 karanas,
  91 attributes).
- Note column is intentionally empty throughout (reserved for
  translator/reviewer notes).
- Coded tables below are generated by `tools/dump_glossary.cpp`
  straight from the source tables (single source of truth,
  re-runnable); the UI term list above it is hand-curated from
  `src/ModernRenderer.hpp` / `src/CLI.cpp`.

## How it's built

- Hand-curated UI section: every header, prompt, label, kendra title,
  and dasa wording in the modern display, read off the renderers.
  Each term appears once. Retired legacy strings (which had no modern
  counterpart) are not listed; the `legacy` branch retains the last
  Old→New table.
- Generated coded tables: `tools/dump_glossary.cpp` prints the modern
  vocabulary straight from the source tables (single source of truth,
  re-runnable): planets, rasis, vargas, all 26 districts, dasa lords,
  nakshatras, weekdays, yogas, tithis, karanas, attributes. Yoni values
  go through the real 10-char display truncation so they match actual
  output.

## Notes worth knowing

- Tithi terms keep the display's internal spacing verbatim
  (e.g. `Pura-Doloswaka  -12`) — Markdown collapses the extra spaces on
  render; the underlying strings carry them.
- The transliterated vocabulary (nakshatras, tithis, karanas,
  attributes) is shared with the engine tables by design — those rows
  exist so translators see the full vocabulary in one place.
